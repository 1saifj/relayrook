# RelayRook visual identity

The mark combines two angular paths into an **R**. One orange route gives it a clear focal point, while the open geometry keeps the silhouette recognizable at small sizes.

| Asset | Use | Dimensions |
| :--- | :--- | :--- |
| [Banner](../assets/relayrook-banner.webp) | README masthead | 2172 × 724 |
| [Icon](../assets/relayrook-icon.webp) | Avatar or project tile | 1254 × 1254 |
| [Banner PNG](../assets/relayrook-banner.png) | Original export | 2172 × 724 |
| [Icon PNG](../assets/relayrook-icon.png) | Original export | 1254 × 1254 |

The opaque dark background makes the assets usable on both light and dark README themes. Keep the existing clear space and preserve the aspect ratio.

Art direction: ink `#101217`, warm white `#F4F1EA`, and signal orange `#FF6B35`. These are the requested palette values; raster output may contain nearby shades.

The assets were created with the built-in image generation tool. [The complete prompts](../assets/prompts.json) record the original direction, banner refinement, and icon extraction. The WebP versions preserve the exact decoded pixels of the PNG originals while reducing file size by roughly 28–30%.
